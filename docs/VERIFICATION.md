## 测试隔离与修正

- Makit 的第一轮数据库测试因未提供专用本机数据库凭据而失败关闭。随后使用已有 PostgreSQL 17 Alpine 镜像创建临时容器：只监听 127.0.0.1 的随机端口，不挂生产目录；执行实际迁移，创建受限应用角色并完成测试。测试库和私有临时 env 文件已删除。隔离脚本拒绝远程 Docker endpoint，并按唯一归属标签确认后清理容器。
- Relay 原锁文件不能支撑独立安装后的完整构建。重新解析依赖图并声明 Nest 打包实际需要的 class-validator / class-transformer 后，构建及 64 项测试通过。没有用原目录依赖链接掩盖缺项。
- WeKnow 移除企业目录后，编译定位出普通搜索入口还直接导入企业 AI hook 和结果组件。已删除该 AI 路径，保留普通搜索、空间过滤和附件结果；新增搜索行为测试。不导入或仿制企业 AI 实现。
- 初次离线安装缺少部分 npm / pnpm 缓存，随后正常从公共 registry 安装。pnpm 超时 CLI 参数还暴露一个类型错误，改用默认参数后冻结锁安装通过。没有为排除故障改变机器全局网络或包管理器配置。
