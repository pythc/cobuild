# 第八批实现：公共代码状态

日期：2026-10-30。基线 `6ad7f9f` / `0.12.0-dev.0`，本批 `0.13.0-dev.0`。范围来自 [Review 08](REVIEW-08.md)，仅完成本地实现与验证，没有线上发布或公开推送。

## 1. 本批行为

Kick 的项目概览新增「代码状态」，复用项目现有仓库链接。用户主动加载公共 GitHub 仓库最近更新的最多 5 个 PR，再按需展开指定 PR 的检查。显示草稿 / 打开 / 关闭 / 已合并、原站链接、提交 SHA、读取时间和缓存状态；不渲染来源 HTML。

PR 检查绑定提供方、主机、原始仓库 ID、PR ID / 编号和 head SHA。读取前后检查 PR head；项目链接 / revision 或用户权限变化时丢弃旧结果。页面刷新、返回、草稿及焦点沿用现有交互；刷新代码摘要后，旧检查请求不能覆盖新提交结果。

两类检查来源分别读取 check runs 和 commit statuses，最多各 20 项。有来源缺失、截断或返回错误时不标记为整体通过；没有检查显示「未发现检查」。通过仅表示本次读到的该 SHA 检查，不代表必需检查齐备、可合并、人工验收或已部署。

## 2. 最小实现与配置

- `packages/code-sources/github-public.mjs`：`summary` / `checks` / `close` 三个小接口，不增加连接器注册平台。
- `workspace-http.mjs`：项目已有身份 / 应用权限核验前后各执行一次；只从持久项目数据取仓库 URL，不接收任意远端 URL。
- `project-code.js`：独立来源视图，来源失败不阻塞项目、需求和空间卡片。
- 配置增加可选 `codeSources.githubPublic`，默认 false；省略字段的旧配置兼容。旧 `integrations.github` 保持关闭，旧 GitHub worker 和写入能力未启用。
- 固定 `https://api.github.com`、GET、无凭据、不跟随重定向。总读取截止 8 秒、单响应 1 MiB、最多 2 个并发逻辑读取、64 个缓存条目、60 秒缓存；合并相同请求，限流后冷却，不后台轮询。
- 启停在进程启动时读取配置；关闭后不读取来源，重启清理缓存，保留项目链接和账号。

没有新增数据库表、迁移、服务、运行依赖或外部写操作。本地预览网络守卫保持默认阻止外部连接；只有显式启用该只读来源且旧集成 / 外发全部关闭时，额外允许 `api.github.com:443`。

**容器核心网络保持 `internal: true`，本批没有开放或验证容器公共 API 出网。** 此开关已验证的是宿主 Node 开发运行；容器启用前需要独立设计受控出网。未构建本批镜像或重跑升级 / 恢复，不用前批结果冒充本批部署验收。

## 4. 自审和修正

1. 原 UI 单元测试只去除单个 import；接入新视图后改为加载实际视图代码，保留已有测试覆盖。
2. 浏览器故障注入的挂起响应存在解除路由时序问题，修正驱动等待后通过；早期失败日志保留，残留的本批临时目录已清理。
3. 刷新摘要时增加请求序号，丢弃旧 head 的迟到结果；增加真实浏览器竞态检查。
4. 检测到 head 或仓库身份变化后清除旧摘要缓存，避免用户必须等待 TTL；追加回归验证 PR 编号和原始 ID 一致。
5. 发现原预览网络守卫阻断所有外部来源，增加上述精确可选例外，随后在真实浏览器中验证实际 GitHub 读取。没有全局放开网络或更改容器隔离。
