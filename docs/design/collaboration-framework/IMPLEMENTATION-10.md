# 第十批实现 · Makit Markdown 与参与筛选

日期为 2026-11-22。套件版本为 `1.0.1`。Makit 功能变更见提交 `7c94e22`。

- 需求介绍、技术方案和自测报告共用编辑器。粘贴 Markdown 时自动排版，支持标题、强调、列表、任务列表、表格和代码块。详情页可显示原始 Markdown、富文本，以及旧编辑器保存为普通段落的 Markdown。
- 验收项支持多行 Markdown。输入时预览，添加后按格式展示并可勾选完成状态。
- 需求池的「我参与的」匹配当前处理人、提出人、产品、研发、测试、FO、发布负责人和关注人。角色匹配使用当前用户的身份 ID。「我的工作」和旧保存视图继续按各自的处理人筛选条件打开。

## 验证范围

Makit 前后端类型检查和自托管前端构建通过。Chrome 使用本地测试数据检查粘贴、保存后重新打开、旧数据展示、验收项预览和参与筛选。参与筛选相关的四组单元测试共 59 项通过。
