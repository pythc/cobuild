## 范围

## 重点检查与处理

1. **导入失败留下半套源码**：改为先验证全部来源，再在私有临时目录复制与核对哈希，最后提交目标目录；异常仅清理本次创建的目录。基线清单用不覆盖已存在文件的方式提交。测试证明后续来源缺失时不会留下前一个组件。
2. **数据与密钥混入源码**：显式选择目录，拒绝符号链接，排除 .env、私有材料、数据库、依赖、构建产物和历史媒体安装包。扫描只输出规则/文件/行号，不输出匹配值。
3. **企业代码随派生版本公开**：排除整个 ee 和 base-formula 目录，保留上游核心许可；删除无效依赖与类型路径，并实际编译定位残留直接导入。完整发行许可审查仍为阻塞。
4. **安装隐式运行平台命令**：移除 Makit 顶层 postinstall 的妙搭初始化及自动 Git hook 设置；构建默认走 selfhost。验证安装使用 ignore-scripts，不能据此承诺所有外部依赖安装钩子已审查。
5. **构建越界打包排除产品**：Platform 的套件构建只编译现有内部应用，不调用桌面插件打包，也不构建实验室公开官网。包装器固定工作目录，避免从错误路径调用旧脚本。
6. **原依赖目录掩盖缺失**：所有组件独立安装；Relay 锁文件和 Nest 可选 peer 的缺项已用构建/测试复核。WeKnow 保持单独 pnpm 工作区，不合并互不兼容的根锁文件。
7. **配置看似生效**：配置工具明确返回 runtimeConfigured=false / runnable=false。可选模块名单是目标，不能把隐藏入口当服务端授权已经完成。
8. **临时数据库误删其他资源**：仅支持本地 Unix Docker endpoint、随机容器名与专属标签、随机 loopback 端口、不挂已有目录；清理前检查归属；异常仍删除临时凭据文件。实际数据库测试后容器已删除。
9. **凭据格式测试被误判**：仅对已查看的合成标记按完整原文件哈希登记；测试内容变化会重新触发扫描，不按 tests 目录整体放过。
10. **过早公开与错误回滚承诺**：根包保持 private，发行检查对未核实事项失败关闭；未发起 Git 远程推送。部署和回退文档要求保留新数据，不执行旧数据库恢复作为默认回退。

## 2026-10-28 · HTTPS 方向与实现 review

先复核 0.5 的证据，确认 HTTP 与人工 Cookie 无法证明 HTTPS 浏览器会话。本轮方向及验收边界先写入 `docs/HTTPS-PLAN.md`，实现保持在部署层，没有修改应用业务源码、身份角色或数据库结构。

1. **证书校验被健康检查绕过**：新入口显式启用 TLS，预检同时核验 SAN、时间、配对和完整链。Node 在禁止出网的容器内实际握手；宿主健康检查连接 loopback 发布端口，仍以公开主机名验证证书，使用正常 CA 校验。
2. **安装 TLS 失败后意外退为 HTTP**：descriptor 固定文件集合与摘要；有遗留材料而缺失记录、软链接或摘要错误时拒绝默认明文。显式传入空证书参数也拒绝。未启用 TLS 的旧部署保持原入口。
3. **私钥写入镜像或错误目录**：材料在私有部署目录内，固定代际名和文件名，不把外部路径拼进代理配置。源密钥拒绝软链接 / 不安全权限，目标 state 也拒绝软链接，写入前检查目录；镜像构建排除私有材料。
4. **代理头改变身份或错误 Host 被转发**：TLS 入口要求准确 Host，清除 Forwarded 并重设转发主机和协议。统一 issuer、回调及内部 HMAC 仍使用配置 origin，内部传输只改变连接位置。
5. **证书更新半成功丢失可用材料**：先写入新私有代际并预检，再原子提交记录。失败前缀清理只删除本次未引用的目录；rename 后 fsync 报错时保留已引用材料，避免有效记录悬空。更新要求业务、数据库和迁移助手全部停止，不自动启动。
6. **证书过期把 pending 永久卡死**：recover 先停止消费者，再预检，错误证书不会先启动数据库或业务。停服时可以修复 TLS，保留 pending 与 schema 状态；仍须显式 recover 才恢复应用。实际 CLI 负向与修复路径独立验证。
7. **旧备份内证书过期**：恢复接受显式新证书，源快照不变，新代际在目标目录验证后提交。不提供新证书时，失败目标保留标记且不启动业务。测试过期材料由夹具构造，不在产品中增加绕过校验开关。
8. **测试器掩盖浏览器边界**：独立 Chrome 实际处理 Cookie、同站导航、授权回调、上下文重开与退出；会话检查使用三个不同主机。浏览器仅固定本轮测试 SPKI，负向上下文没有该固定；信任链另由 CA 客户端验证，不安装系统信任或关闭全局校验。
9. **校验助手或浏览器遗留**：TLS 助手带归属标签、内外超时和 finally 清理，标签不符拒绝删除。浏览器使用临时上下文并在 finally 关闭；测试器只处理专属容器、网络和卷。首次完整演练的浏览器因驱动期待的版本缺失而未启动，改为显式使用已有 Chrome 后复测；该失败轮次不计为完整通过。

完整结果见 `provenance/https-checks.json`。这些检查覆盖本机 TLS 与会话，不替代目标主机的公网 DNS、公有 CA、真实续期、容量、跨机器恢复或发行许可验收。
